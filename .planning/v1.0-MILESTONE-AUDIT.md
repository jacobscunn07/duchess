## Integration Gaps

### GAP-01: cfg.RefreshInterval not wired to tickers (CONF-01, CONF-02)

**Severity:** Functional gap — requirement not met
**Files affected:**
- `internal/ui/model.go:236` — clock tick hardcoded `time.Second`
- `internal/ui/s3/client.go:133` — S3 refresh hardcoded `30*time.Second`
- `internal/ui/ecs/client.go:214` — ECS cluster refresh hardcoded `10*time.Second`
- `internal/ui/ecs/client.go:222` — ECS service refresh hardcoded `10*time.Second`
- `internal/ui/ecs/client.go:231` — ECS task refresh hardcoded `5*time.Second`

**Root cause:** `cfg.RefreshInterval` flows through `LoadConfig → NewRootModel` but is stored in `rootModel.cfg` and never forwarded to panel constructors or tick commands. All five tick commands use hardcoded `time.Duration` literals.

**Fix:** Pass `cfg.RefreshInterval` as a parameter through `NewRootModel` into `s3panel.NewModel` and `ecspanel.NewModel`. Replace hardcoded durations in tick commands with the passed-in value.

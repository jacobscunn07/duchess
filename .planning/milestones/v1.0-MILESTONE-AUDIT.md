### Integration Observations (Non-Blocking)

1. **`taskDetailErrMsg` missing `m.refreshing = false`** (`ecs/model.go:254-260`): All other ECS error handlers reset both `m.loading` and `m.refreshing`. `taskDetailErrMsg` only resets `m.loading`. Since `FetchTaskDetailCmd` is dispatched from `descendIntoSelected` (not a refresh ticker), `m.refreshing` is typically false in this path. No user-visible regression expected in normal use.

2. **Stale "30-second" comment** (`s3/messages.go:44`): Predates Phase 4.1. Runtime behavior is correct (`S3RefreshTickCmd(d time.Duration)`). Cosmetic only.

3. **`regionSelectedMsg` does not re-fetch STS identity** — correct by design. Region switch mutates `m.awsCfg.Region` in place; the credential chain is region-independent; only ECS (regional) needs panel reset. S3 bucket listing is global-region.

Create directory internal/config/.

Write internal/config/config.go:
- Package config
- Config struct with yaml tags: Profile string `yaml:"profile"`, Region string `yaml:"region"`, RefreshInterval int `yaml:"refresh_interval"`
- LoadConfig(cmd *cobra.Command) (*Config, error) function:
  1. Initialize cfg := &Config{RefreshInterval: 2}
  2. Get home dir via os.UserHomeDir() — never use "~" string expansion
  3. configPath := filepath.Join(home, ".duchess", "config")
  4. Read file with os.ReadFile(configPath); if err is nil, yaml.Unmarshal into cfg; if yaml error, return wrapped error fmt.Errorf("parse config: %w", err)
  5. If ReadFile returns error, skip silently (file missing is acceptable)
  6. Apply flag overrides ONLY for flags that were explicitly set:
     - if cmd.Flags().Changed("profile") { cfg.Profile, _ = cmd.Flags().GetString("profile") }
     - if cmd.Flags().Changed("region") { cfg.Region, _ = cmd.Flags().GetString("region") }
     - if cmd.Flags().Changed("refresh-interval") { cfg.RefreshInterval, _ = cmd.Flags().GetInt("refresh-interval") }
  7. Return cfg, nil

Imports: cobra, yaml.v3, os, path/filepath, fmt

Implement the region picker overlay and wire it into rootModel. When the user presses r in stateReady or stateError, a centered modal overlay appears listing all standard AWS commercial regions with the current region pre-selected. Selecting a region cancels in-flight goroutines, updates awsCfg.Region, resets ECS panel to cluster list for the new region, leaves S3 panel unchanged, and immediately updates the status bar.

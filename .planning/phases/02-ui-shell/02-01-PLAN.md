Create two files in a new `internal/ui/` directory.

**internal/ui/messages.go** — custom Bubble Tea message types:
```go
package ui

import "time"

// identityLoadedMsg is sent when STS GetCallerIdentity succeeds.
type identityLoadedMsg struct {
    account string
    arn     string
}

// identityErrMsg is sent when STS GetCallerIdentity fails.
// err is already classified via session.ClassifyCredentialError.
type identityErrMsg struct {
    err error
}

// tickMsg is sent every second to advance the clock in the status bar.
type tickMsg time.Time
```

**internal/ui/model.go** — root model implementing tea.Model:

Define a `state` type with constants `stateLoading`, `stateReady`, `stateError`.

The `rootModel` struct holds:
- `ctx context.Context`
- `awsCfg aws.Config`
- `cfg *config.Config`
- `width, height int`
- `state state`
- `spinner spinner.Model`
- `now time.Time`
- `account, arn string`
- `err error`

`NewRootModel(ctx context.Context, cfg *config.Config, awsCfg aws.Config) rootModel`:
- Initialize spinner with `spinner.New(spinner.WithSpinner(spinner.Dot), spinner.WithStyle(lipgloss.NewStyle().Foreground(lipgloss.Color("205"))))`
- Set `state: stateLoading`, `now: time.Now()`, `width: 80`, `height: 24`
- NO_COLOR guard: if `os.Getenv("NO_COLOR") != ""` then call `lipgloss.SetColorProfile(termenv.Ascii)` — import `"github.com/muesli/termenv"` for the Ascii constant

`Init()` returns:
```go
tea.Batch(
    fetchIdentityCmd(m.ctx, m.awsCfg, m.cfg.Profile),
    m.spinner.Tick,
    tickCmd(),
)
```

`fetchIdentityCmd(ctx context.Context, awsCfg aws.Config, profile string) tea.Cmd` — a package-level function (not a method) that wraps `session.GetCallerIdentity` asynchronously. It must ALWAYS return a closure (never nil). On success, return `identityLoadedMsg{account, arn}`. On error, return `identityErrMsg{err: session.ClassifyCredentialError(err, profile)}`.

`tickCmd() tea.Cmd` — package-level function: `tea.Tick(time.Second, func(t time.Time) tea.Msg { return tickMsg(t) })`.

`Update(msg tea.Msg) (tea.Model, tea.Cmd)` handles:
- `tea.WindowSizeMsg`: set m.width, m.height; return m, nil
- `tea.KeyMsg` "q" or "ctrl+c": return m, tea.Quit (NOT tea.Quit())
- `identityLoadedMsg`: set m.account, m.arn, m.state = stateReady; return m, nil
- `identityErrMsg`: set m.err, m.state = stateError; return m, nil
- `tickMsg`: set m.now = time.Time(msg); return m, tickCmd()
- `spinner.TickMsg`: only propagate when m.state == stateLoading (swallow otherwise to stop spinner)
- default: return m, nil

`View() string` — skeleton for this plan (status bar implemented in Plan 02):
- If m.width == 0: return "" (guard against zero-dimension before WindowSizeMsg)
- Return a placeholder that renders non-empty: `lipgloss.NewStyle().Width(m.width).Height(m.height).Render("")`
